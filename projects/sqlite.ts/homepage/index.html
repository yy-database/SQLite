sqlite-format3

读写 SQLite 主文件与原始页快照的独立实现。三个绑定共用同一套纯 Rust 页面与记录层，不依赖上游 SQLite 引擎。

能力

能力Node-APIPyO3WebAssembly
读取普通表、索引、视图、触发器是是否
读取 WITHOUT ROWID 表是是否
读取 UTF-8 / UTF-16 文本是是仅写入 UTF-8
回放 -wal 与热 journal是是否
创建表、索引、插入、更新、删除、事务是是仅建表与插入
执行 SQL否否受限子集
导出内存页快照是是是

WebAssembly 的 SQL 子集仅接受 CREATE TABLE、INSERT、SELECT count(*) / 列投影 + LIMIT，其余语句结构化拒绝。
